# Week 3: Sweet Shop (UI & API)

## Overview

This folder contains both UI and API automation assignments for the Sweet Shop project.

### Structure

- All UI Playwright tests are in `tests/`
- All API Playwright tests are in `api-tests/`


## How to Run

From the root of your repository:

### UI Tests
```
npx playwright test Week-3-SweetShop/tests
```

### API Tests
```
npx playwright test Week-3-SweetShop/api-tests
```

### View Reports
```
npx playwright show-report
```
